### Unified GRISP OS UI Specification (Best of All Worlds)

This specification synthesizes the strongest elements from all provided images into a single, definitive user interface.

#### 1. Layout Architecture (Three-Column IDE Style)
*   **Left Column (Context & Navigation):** 
    *   **Resource Explorer:** Tree view with inline permissions (R/W/X) (Image 1, 11). 
    *   **Session History:** List of past chats with timestamps (Image 1, 3, 7, 11).
    *   **Quick Actions:** Buttons to "Add Resource" or "New Session" (Image 5).
*   **Middle Column (Interaction & Reasoning):**
    *   **Chat Workspace:** Standard User/Assistant message bubbles.
    *   **Collapsible "Thinking" Blocks:** A toggleable section (F3/Ctrl+T) that shows the AI's chain of thought, parsing steps, and cross-referencing (Image 3, 5, 8).
    *   **Quick Action Prompts:** Buttons like "Analyze Project", "Search Knowledge", "Generate Report" at the top of a new chat (Image 5).
    *   **Input Bar:** Bottom of the column, with support for slash commands (e.g., `/refactor`, `/plan`) (Image 9).
*   **Right Column (State & Execution):**
    *   **Current Plan:** A dynamic checklist with statuses (Done, Running, Queued, Pending) (Image 3, 7).
    *   **Work Items:** Prioritized task list with tags (High, Medium, Low) (Image 3, 4, 6).
    *   **Metadata/Relations:** Optional collapsible panel showing MIME registry, Agent Network, or file relations (Image 5).

#### 2. Top Navigation Bar
*   **Primary Tabs:** Explorer, Agents, Workflows, Knowledge, Models, Tools, Terminal, Settings (Image 1, 3, 5).
*   **Global Actions:** "+ New Chat", Theme Toggle, Notifications, Agent Status Indicator (e.g., "Agent: Alex Ready") (Image 3, 5).

#### 3. Bottom Status Bar
*   **Left:** Connection Status (e.g., "Connected"), Active Project (e.g., "GRISP://Workspace").
*   **Center:** Active Model (e.g., "Model: GPT-5"), Session count (e.g., "Sessions: 1/4").
*   **Right:** Active Permissions (R/W/X) and Security indicators (Image 1, 3, 5, 11).
*   **Export Options:** Buttons for exporting chat/plan (UNICODE, ASCII, ANSI) (Image 6).

#### 4. Visual Style & Themes
*   **GUI Mode:** Modern dark theme (deep blues/blacks) with high-contrast cyan, green, and magenta accents for statuses (Image 3, 5).
*   **TUI Mode (Terminal):** Clean, box-drawing ASCII layout with monospace fonts. Distinct color coding for user input (green), AI response (cyan), and system logs (yellow/grey) (Image 7, 8, 10, 11).
*   **Permission Badges:** Small, color-coded badges for Read (R), Write (W), and Execute (X) next to every file/folder in the explorer (Image 1, 11).

#### 5. Key Interactions
*   **Audit Trail:** Users can expand any "Thinking" block to see the exact SIR -> Planner -> Evaluator -> Validator steps the AI took (Image 4, 6).
*   **Direct Manipulation:** Users can check off "Work Items" or re-prioritize tasks in the right panel, which updates the AI's context automatically.
*   **Graceful Degradation:** The UI transitions seamlessly from a full GUI (Image 3/5) to a TUI (Image 11) depending on the environment (Desktop vs. SSH/Terminal).
*   **Multilingual Support:** The AI can process and respond in different languages (as seen with the Dutch "Begrepen" in Image 6) while maintaining the UI in English.
