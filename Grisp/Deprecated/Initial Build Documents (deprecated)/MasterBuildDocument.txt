# 1. Purpose

Anti Gravity 2.0 must generate a complete implementation of **GRISP 1.0**, the:

**G**raph  
**R**ewrite  
**I**nformation  
**S**ymbolic  
**P**rocessor  

GRISP 1.0 is a **graph‑native symbolic programming system** where:

- Programs are graphs  
- Data is graphs  
- Rewrite rules are graphs  
- Execution is graph rewriting  
- Syntax is **G‑Blocks**  
- Implementation language is **Delphi**  

Anti Gravity 2.0 must generate:

1. Graph engine  
2. G‑Blocks parser  
3. Pattern matcher  
4. Rewrite engine  
5. Runtime loop  
6. Optional visualization hooks

```

```

# 2. Core Data Model (Delphi)

Anti Gravity 2.0 must generate the following units:

```
unit_GrispGraph_version_001.pas
```

Containing:

### 2.1 `TGValueKind`
```
vkNumber, vkString, vkBoolean, vkIdentifier, vkArray, vkNode
```

### 2.2 `TGValue`
Represents a typed G‑Blocks value.

Fields:

- `Kind: TGValueKind`
- `NumberValue: Double`
- `StringValue: string`
- `BoolValue: Boolean`
- `IdentifierValue: string`
- `ArrayValue: TObjectList<TGValue>`
- `NodeValue: TGNode`

### 2.3 `TGNode`
Represents a G‑Block node.

Fields:

- `Id: Integer`
- `Name: string`
- `NodeType: string`
- `Attributes: TObjectDictionary<string, TGValue>`
- `Outgoing: TObjectList<TGEdge>`

### 2.4 `TGEdge`
Represents a labeled, typed connection.

Fields:

- `LabelName: string`
- `EdgeType: string`
- `Source: TGNode`
- `Target: TGNode`

### 2.5 `TGGraph`
Represents a complete GRISP program.

Fields:

- `Nodes: TObjectList<TGNode>`
- `Edges: TObjectList<TGEdge>`
- `NodeIndex: TObjectDictionary<string, TGNode>`
- `Rules: TObjectList<TGNode>`

Methods:

- `AddNode`
- `AddEdge`
- `FindNode`
- `RegisterRule`

# 3. G‑Blocks Parser Architecture

Anti Gravity 2.0 must generate:

```
unit_GrispTokens_version_001.pas
unit_GrispLexer_version_001.pas
unit_GrispParser_version_001.pas
unit_GrispGBlocks_version_001.pas
```

### 3.1 Lexer  
Recognizes:

- identifiers  
- numbers  
- strings  
- booleans  
- keywords: `node`, `array`, `true`, `false`  
- symbols: `{ } [ ] < > : = ,`  

### 3.2 Parser  
Parses:

```
node <Name> {
    <EdgeName>: <Type> = <Value>
}
```

Supported types:

- `number`
- `string`
- `boolean`
- `identifier`
- `array<T>`
- `node`

Supported values:

- literals  
- identifiers  
- arrays  
- nested nodes  

Parser must:

- Build `TGNode`  
- Build `TGValue`  
- Build edges implicitly from attributes  
- Insert nodes into `TGGraph`  
- Register rule nodes (`rule.*`)

# 4. Pattern Matcher Architecture

Anti Gravity 2.0 must generate:

```
unit_GrispPattern_version_001.pas
```

Containing:

### 4.1 `TMatchResult`
Fields:

- `Success: Boolean`
- `NodeBindings: TList<TNodeBinding>`
- `ValueBindings: TList<TValueBinding>`

### 4.2 `TGrispPatternMatcher`
Methods:

- `MatchPattern(PatternRoot: TGNode): TMatchResult`
- `MatchNodePattern`
- `MatchAttributePattern`

### 4.3 Responsibilities

- Structural graph unification  
- Variable binding  
- Literal matching  
- Nested node matching  
- Type checking  

The matcher **does not modify the graph**.

# 5. Rewrite Engine Architecture

Anti Gravity 2.0 must generate:

```
unit_GrispRewrite_version_001.pas
```

Containing:

### 5.1 `TGrispRewriter`
Methods:

- `ApplyRuleOnce(ARule: TGNode; Matcher: TGrispPatternMatcher): Boolean`
- `GetMatchRoot`
- `GetRewriteRoot`
- `BuildRewriteSubgraph`
- `ApplyRewriteToGraph`

### 5.2 Responsibilities

- Substitute variables from `TMatchResult`
- Build replacement subgraph
- Modify graph:
  - update attributes  
  - create nodes  
  - create edges  
  - rewire connections  
  - delete or detach old nodes if needed  

The rewriter **does not search for matches**.

# 6. Runtime Loop Architecture

Anti Gravity 2.0 must generate:

```
unit_GrispRuntime_version_001.pas
```

Containing:

### 6.1 `TGrispRuntime.Run(Graph, MaxSteps)`
Responsibilities:

- Initialize matcher + rewriter  
- Iterate over rules  
- Apply rules until:
  - no rule matches  
  - or max steps reached  

Returns:

- number of rewrite steps performed  

Mode: **deterministic**.

# 7. Rule Structure

A rule is a node whose name starts with `rule.`:

```
node rule.example {
    match: node = { ... }
    rewrite: node = { ... }
}
```

Parser must:

- Store rule in `Graph.Rules`
- Extract `match` and `rewrite` as nested `TGNode` structures

---

# 8. Minimal Example (Required)

Anti Gravity 2.0 must support:

```
node A {
    value: number = 1
    next: identifier = B
}

node B {
    value: number = 2
}

node rule.swap-if-greater {
    match: node = {
        X: node = {
            value: number = 2
            next: identifier = Y
        }
        Y: node = {
            value: number = 1
        }
    }

    rewrite: node = {
        X: node = {
            value: number = 1
            next: identifier = Y
        }
        Y: node = {
            value: number = 2
        }
    }
}
```

Expected:

- Parser builds graph  
- Rule registered  
- Pattern does not match initially  
- If values swapped → rule fires
