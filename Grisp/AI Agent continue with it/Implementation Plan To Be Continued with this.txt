Implementation Plan - Hardening & Firefox Web AI Integration
Overview
This implementation plan addresses the feedback in 
Implementation Feedback.txt
 and integrates the Firefox Web AI automation communication layer from 
FireFoxWithChatAI
 and 
AIConsoleTool.dpr
.

Key Objectives
FireFoxWithChatAI TCP Peer Integration:

Implement TFirefoxChatAIPeer (in MLCRD_FirefoxPeer.pas & MLCRD_Peers.pas) using Indy TIdTCPClient.
Connect to Firefox on localhost:9999 (configurable).
Support all 8 AI sites: deepseek (default), gemini, claude, chatgpt, copilot, grok, perplexity, inception.
Implement multi-stage prompt formatting and response extraction (candidates, critiques, cross-repairs, capability requests, test programs, scores).
Add tab querying and tab session reuse.
Graceful connection error handling and fallback.
GRISP VFS & Capability Hardening (from Implementation Feedback):

ResolveSafe in TGrispVfs: reject drive letters, reject .., normalize paths, compute TPath.GetFullPath, and strictly verify that physical path starts with FSandboxPhysicalRoot.
Content- and extension-based MIME validation: map extensions (.c, .pas, .py, .json, .txt, .bin) to trusted MIME types and validate in TGrispCapability.
Structured TValidationResult record for plan validation: Accepted: Boolean, FailedOps: TArray<string>, Diagnostics: string.
Comprehensive error checks and return value validation across all VFS and engine methods.
CLI Expansion:

Add --firefox and --sites <list> (e.g. --sites deepseek,gemini,claude) to GrispAgentCLI.dpr.
Add --list-tabs and --open-tab <url> options.
Add automated test cases in GrispAgentTests.dpr.
