# Contributing to GRISP

Thank you for your interest in contributing to GRISP!

GRISP is an experimental AI‑native programming language, and contributions are welcome in the following areas:

- Parser improvements  
- Pattern matcher enhancements  
- Rewrite engine optimizations  
- Visualization tools  
- Documentation  
- Example programs  
- Bug fixes  
- Performance improvements  

---

## How to Contribute

### 1. Fork the repository  
Create your own fork and clone it locally.

### 2. Create a feature branch  
git checkout -b feature/my-improvement

Code

### 3. Make your changes  
Follow the existing coding style and naming conventions.

### 4. Add tests  
All new features must include tests in `GrispTestProject.dpr`.

### 5. Submit a pull request  
Describe your changes clearly and reference any related issues.

---

## Coding Guidelines

- Use clear, descriptive names  
- Keep units small and focused  
- Avoid unnecessary complexity  
- Maintain deterministic behavior  
- Ensure all graph modifications are explicit and safe  

---

## Reporting Issues

Please include:

- Steps to reproduce  
- Expected behavior  
- Actual behavior  
- Code samples or G‑Blocks snippets  

---

## Thank You

Your contributions help shape the future of AI‑native programming.
