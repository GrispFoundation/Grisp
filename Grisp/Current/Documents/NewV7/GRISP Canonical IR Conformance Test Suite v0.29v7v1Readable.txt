# GRISP Canonical IR Conformance Test Suite v0.29v7v1 (Readable)

## Normative Companion Document (Readable Edition)

This document provides **5 canonical manifests** in GRISP Canonical JSON, each accompanied by expected golden file fragments (tick records, events, final state) and a **runner checklist** for implementers. All manifests conform to the GRISP Canonical IR Specification v0.29v5 and are intended to validate engine conformance.

> **Note on readability:** The JSON examples below are formatted with indentation and line breaks for human readability. **For byte‑exact conformance comparison, engines MUST normalize all outputs to GRISP Canonical JSON as defined in IR-018** (minified, keys sorted lexicographically, no whitespace outside strings). The normative representation is the minified form; the pretty‑printed form here is for illustration only.

---

## Runner Checklist for Implementers

For each manifest:

1. **Load** the Canonical IR document (ensure strict GRISP Canonical JSON parsing – IR-018).
2. **Execute** the engine starting from the specified initial state.
3. **Capture** the golden file output (tick records, events, final state).
4. **Normalize** the captured output to GRISP Canonical JSON (minify, sort keys).
5. **Compare** the normalized output with the expected minified golden file (provided separately in the normative conformance pack or generated from the readable fragments by applying IR-018 rules).
6. **Verify** that all observable behavior matches exactly (byte‑for‑byte).
7. **Repeat** for all 5 manifests.

**Pass criteria:** The engine produces identical golden file output (after normalization) for each manifest.
