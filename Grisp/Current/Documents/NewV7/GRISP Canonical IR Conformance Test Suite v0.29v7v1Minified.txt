# GRISP Canonical IR Conformance Test Suite v0.29v7v1 (Minified)

## Normative Companion Document

This document provides a **conformance test suite** for the GRISP Canonical IR Specification v0.29v5 (Freeze Edition). It contains five canonical manifests in GRISP Canonical JSON, expected golden file fragments, and a runner checklist. Engines claiming conformance SHALL pass all tests described herein.

---

## Runner Checklist for Implementers

For each manifest:

1. **Load** the Canonical IR document (ensure strict GRISP Canonical JSON parsing).
2. **Execute** the engine starting from the specified initial state.
3. **Capture** the golden file output (tick records, events, final state).
4. **Compare** the captured output with the expected fragments below. Use byte‑exact comparison for JSON fields after ignoring non‑normative metadata (e.g., comments, timestamps).
5. **Verify** that all observable behavior matches exactly (state, events, version counters, error records).
6. **Repeat** for all 5 manifests.

**Pass criteria:** The engine produces identical golden file output (modulo non‑normative metadata) for each manifest when compared to the expected output defined in this suite.
