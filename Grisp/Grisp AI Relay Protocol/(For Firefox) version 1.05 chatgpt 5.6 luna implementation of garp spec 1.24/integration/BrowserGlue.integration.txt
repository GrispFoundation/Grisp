# GARP/1.24 BrowserGlue integration

Add the module getter to the existing ChromeUtils.defineESModuleGetters(lazy, {...}) block:

AIAutomationService: "resource:///modules/aistarter/AIAutomation.sys.mjs",

In BrowserGlue.prototype._init, after core browser state exists:

try {
  this.aiAutomationService = new lazy.AIAutomationService();
  this.aiAutomationService.init();
} catch (ex) {
  Cu.reportError("AIAutomationService init failed: " + ex);
}

Do not create a second AIAutomationService instance.

GARP/1.24 requires GARP_SECRET to be deployment-provisioned and contain at least 32 raw UTF-8 bytes. The gateway does not generate a development secret.
