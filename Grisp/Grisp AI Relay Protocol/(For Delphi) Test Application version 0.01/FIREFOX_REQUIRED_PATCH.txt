GARP/1.01 FIREFOX COMPATIBILITY PATCH

The Delphi tester follows the GARP/1.01 handshake and therefore sends HELLO_AUTH as a distinct numeric message type.

In browser/components/aistarter/garp/GarpRegistry.sys.mjs, add HELLO_AUTH to GarpMessageType using an unused value:

  HELLO_AUTH: 0x0007,

and therefore map it in both directions automatically through the existing Object.entries() maps.

No change is required to handleHelloAuth() in AIAutomation.sys.mjs; that handler already recognizes the semantic message type "hello_auth".

This patch is required because the original Firefox-side registry contains HELLO_CHALLENGE (0x0005) and RESPONSE (0x0006) but did not assign a numeric wire type to HELLO_AUTH.
