# GARP/1.24 BrowserGlue startup integration

The module is packaged at:
    resource:///modules/aistarter/AIAutomation.sys.mjs

Create exactly one service instance per Firefox process.

Example:

    const { AIAutomationService } = ChromeUtils.importESModule(
      "resource:///modules/aistarter/AIAutomation.sys.mjs"
    );

    this._garpAutomationService ??= new AIAutomationService();
    this._garpAutomationService.init();

At shutdown:

    this._garpAutomationService?.shutdown();
    this._garpAutomationService = null;

Use the existing Firefox startup/shutdown lifecycle. Do not replace BrowserGlue.sys.mjs
and do not instantiate the service once per browser window.
