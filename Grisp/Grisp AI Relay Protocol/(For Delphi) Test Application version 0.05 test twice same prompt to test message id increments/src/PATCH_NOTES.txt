GARP/1.24 Delphi Client v20

Fix:
- GARP124.Client.pas ReceiveUntilPromptEvent no longer treats INPUT_SUBMITTED as terminal.
- Intermediate prompt lifecycle events (INPUT_SUBMITTED, GENERATION_STARTED,
  GENERATION_DELTA, GENERATION_PROGRESS, CONTINUATION_REQUIRED,
  CONTINUATION_SUBMITTED and diagnostic/provider lifecycle events) are consumed
  while waiting for the actual terminal event.
- WaitForCompletion now returns only:
    GENERATION_COMPLETED
    GENERATION_FAILED
    GENERATION_CANCELLED
- This prevents RunConformance/RunLiveBasic from closing the Firefox session
  immediately after INPUT_SUBMITTED while generation is still streaming.

Based on the client source that produced the successful DeepSeek submission trace
on 2026-09-16.
