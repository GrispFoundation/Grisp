# GARP/1.24 DesktopActorRegistry integration

Inside the existing JSWINDOWACTORS registry add:

AIAutomation: {
  parent: {
    esModuleURI: "resource:///modules/aistarter/actors/AIAutomationParent.sys.mjs",
  },
  child: {
    esModuleURI: "resource:///modules/aistarter/actors/AIAutomationChild.sys.mjs",
  },
  allFrames: true,
  safeForUntrustedWebProcess: true,
},

The actor name MUST remain AIAutomation because the parent-side gateway obtains it with:

getActor("AIAutomation")
