# GARP/1.01 BrowserGlue integration

## 1. Add to the existing ChromeUtils.defineESModuleGetters(lazy, {...}) block:

AIAutomationService: "resource:///modules/aistarter/AIAutomation.sys.mjs",

## 2. In BrowserGlue.prototype._init, after core browser state exists:

try {
  this.aiAutomationService = new lazy.AIAutomationService();
  this.aiAutomationService.init();
} catch (ex) {
  Cu.reportError("AIAutomationService init failed: " + ex);
}

Do not create a second AIAutomationService instance elsewhere.
