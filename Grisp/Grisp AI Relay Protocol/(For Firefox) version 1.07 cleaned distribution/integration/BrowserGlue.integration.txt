# GARP/1.24 BrowserGlue startup integration

The GARP component exposes AIAutomationService from:

    browser/components/aistarter/AIAutomation.sys.mjs

Integrate it into the Firefox desktop startup/shutdown path used by the checkout.

The intended lifecycle is exactly one service instance per Firefox process:

    Firefox startup
        -> import resource:///modules/aistarter/AIAutomation.sys.mjs
        -> new AIAutomationService()
        -> service.init()

On application shutdown:

    service.shutdown()

Do not construct one service per browser window and do not start multiple GARP listeners.

The exact BrowserGlue insertion point is Firefox-tree dependent. Use the existing
startup and shutdown observer/lifecycle code in the checkout rather than replacing
BrowserGlue.sys.mjs. The component is intentionally not auto-patched.
