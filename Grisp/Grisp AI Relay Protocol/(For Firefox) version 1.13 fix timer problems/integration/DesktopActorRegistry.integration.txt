# GARP/1.24 JSWindowActor integration

Register the AIAutomation JSWindowActor pair in the existing desktop JSWINDOWACTORS
registry for the Firefox checkout.

Expected registration:

AIAutomation: {
  parent: {
    esModuleURI: "resource:///modules/aistarter/actors/AIAutomationParent.sys.mjs",
  },
  child: {
    esModuleURI: "resource:///modules/aistarter/actors/AIAutomationChild.sys.mjs",
  },
  allFrames: true,
  safeForUntrustedWebProcess: true,
},

The actor name must be exactly:

    AIAutomation

The actor files are ordinary JavaScript modules installed by the single
browser/components/aistarter/moz.build file under:

    resource:///modules/aistarter/actors/

After startup, the parent side obtains the actor with:

    windowGlobal.getActor("AIAutomation")
