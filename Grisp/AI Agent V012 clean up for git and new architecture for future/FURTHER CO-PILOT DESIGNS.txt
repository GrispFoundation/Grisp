### 1. High-level goals (one paragraph)
GRISP v1.0 is a deterministic, evidence-driven agent runtime that treats LLMs as **untrusted reasoning workers**. All AI-produced artifacts must be parsed into a strict internal representation (`ArtifactBundle`), every objective operation must produce structured `Evidence`, and final acceptance is decided by deterministic gates that require objective verification (compile/test/policy) and cryptographic artifact identity. Firefox (or any browser gateway) is a stateful transport implementing **GARP/1.0**; providers may return free-form text, but GRISP accepts only parsed `ArtifactBundle` objects or rejects the response.

### 3. Deterministic State Machine (orchestrator)

Use a deterministic state machine with explicit transitions and no implicit success paths. Each transition requires evidence. Below is the canonical state graph and transition conditions.

#### States
- `TASK_ACCEPTED`
- `TASK_NORMALIZED`
- `WORKER_PLAN` (optional)
- `CANDIDATE_GENERATION`
- `ARTIFACT_PARSE`
- `STATIC_VALIDATION`
- `COMPILE_PENDING`
- `COMPILED`
- `RUNTIME_PENDING`
- `RUNTIME_VERIFIED`
- `TEST_PENDING`
- `TEST_VERIFIED`
- `ADVERSARIAL_REVIEW`
- `CANDIDATE_RANKING`
- `FINAL_VERIFICATION`
- `COMMIT_PENDING`
- `COMMITTED`
- Failure states: `PARSE_FAILED`, `STATIC_FAILED`, `COMPILE_FAILED`, `RUNTIME_FAILED`, `TEST_FAILED`, `POLICY_REJECTED`, `TIMEOUT`, `VERIFICATION_FAILED`

#### Transition rules (examples)
- `TASK_ACCEPTED -> TASK_NORMALIZED` : always (normalizer produces canonical `Task`).
- `TASK_NORMALIZED -> CANDIDATE_GENERATION` : when orchestrator issues `PROMPT` to workers.
- `CANDIDATE_GENERATION -> ARTIFACT_PARSE` : when worker response arrives (response envelope).
- `ARTIFACT_PARSE -> STATIC_VALIDATION` : if parse succeeded and `ArtifactBundle` created; else `PARSE_FAILED`.
- `STATIC_VALIDATION -> COMPILE_PENDING` : if static checks pass for artifact kind requiring compilation; else `STATIC_FAILED`.
- `COMPILE_PENDING -> COMPILED` : on `ToolResult` with `status=ok` and `diagnostics` empty for errors.
- `COMPILED -> TEST_PENDING` : if tests exist; else skip to `ADVERSARIAL_REVIEW` or `CANDIDATE_RANKING`.
- `TEST_PENDING -> TEST_VERIFIED` : if all required tests pass (objective oracles satisfied).
- `TEST_VERIFIED -> FINAL_VERIFICATION` : run final re-hash and re-run compile/test on exact bytes.
- `FINAL_VERIFICATION -> COMMIT_PENDING` : if all gates pass.
- `COMMIT_PENDING -> COMMITTED` : transactional commit succeeds.
- Any failure state prevents acceptance; no automatic transition from failure to accepted.

### 4. Hard Acceptance Gate (deterministic rule)

A candidate is **ACCEPTABLE** iff all of the following are true:

1. `artifact_valid` — `ArtifactBundle` parsed and `artifact_id` computed.
2. `policy_valid` — policy engine returns `pass` for required policy checks.
3. `all_required_objective_checks_pass` — for each required operation (compile, run, tests) the corresponding `Evidence` has `status == ok` and diagnostics contain no `severity == error`.
4. `final_artifact_hash == verified_artifact_hash` — final verification re-hashes the bytes to match the artifact identity used in evidence.

If any of these are false, the candidate is **REJECTED**. Subjective LLM scores may be used only for ranking among **eligible** candidates (those that passed the objective gates).

### 5. Artifact parsing rules (strict)

- **Fast path**: If worker returns a structured envelope matching `ArtifactBundle` schema, accept it as parsed (still compute and verify `sha256`).
- **Compatibility path**: If worker returns Markdown, attempt deterministic extraction:
  - Accept only a single unambiguous code block per file. If multiple code blocks map to the same filename, **PARSE_ERROR**.
  - If a filename header is present (e.g., `Pascal/Delphi:HelloWorld.dpr`), use it; otherwise, derive filename from language and artifact kind.
  - Reject any response that contains non-code tokens interleaved inside code fences (e.g., `delphiCopyDownload`).
- **Ambiguous**: If extraction yields multiple plausible interpretations or missing required fields, return `PARSE_ERROR` and request repair.
- **No guessing**: Do not attempt to heuristically "fix" ambiguous content; request a repair prompt with the original response and diagnostics.

### 6. Evidence model and storage

- Every tool invocation (parse, compile, run, test, policy check) MUST produce an `Evidence` record stored in the Evidence DB.
- Evidence records are immutable and referenced by `Decision`.
- Evidence must include `input_hash` and `output_hash` to enable replay and re-verification.
- Evidence DB must support queries by `artifact_id`, `task_id`, `operation`, and `worker_id`.

### 7. Tool engine semantics (deterministic contract)

- Tools return `ToolResult` objects (not booleans).
- `compile` must return diagnostics array with line numbers and error codes.
- `run` must return stdout, stderr, exit code, and resource usage.
- `hash` must return canonical SHA-256 of bytes (use canonical serialization for `ArtifactBundle`).
- All tool results are recorded as `Evidence`.

### 8. GARP/1.0 (Firefox AI Gateway) — wire-level summary

**Transport:** TCP localhost framed messages (length-prefixed). Use a simple frame: 4-byte BE length + JSON payload. Include `request_id` and `session_id` in every message.

**Core message fields (JSON):**
```json
{
  "protocol":"GARP/1.0",
  "type":"prompt|prompt_ack|generation_delta|generation_completed|get_response|response_event|ping|hello",
  "request_id":"uuid",
  "session_id":"uuid",
  "tab_id":"uuid",
  "message_id":"uuid",
  "sequence": 1,
  "payload": { ... }
}
```

**Key behaviors:**
- `PROMPT` returns immediate `prompt_ack` with `request_id`.
- Responses stream as `generation_delta` events with `sequence` numbers; final event is `generation_completed`.
- `CANCEL_PROMPT` cancels in-flight generation; gateway must propagate cancellation to provider and return `generation_failed` or `cancelled`.
- `LIST_TABS`, `OPEN_TAB`, `CLOSE_TAB` use stable `tab_id` GUIDs (not numeric indices).
- `CREATE_SESSION` binds a `session_id` to a provider and tab.
- Gateway must support `subscribe_response` to receive events rather than polling.

**Compatibility:** Providers need not implement GARP; Firefox gateway adapts provider UI and returns structured events to GRISP. GRISP must parse provider text into `ArtifactBundle` at the boundary.

### 10. Test architecture and quality rules

- Tests must target the actual artifact (black-box for executables).
- Each test must declare:
  - `test_target` (artifact filename or executable)
  - `test_type` (black_box|unit|integration|property)
  - `oracle` (stdout_exact, exit_code, file_exists, etc.)
  - `coverage_intent` (what the test aims to exercise)
- Tests that invent internal functions not present in artifact are `TEST_INVALID`.
- Test evidence is recorded as `Evidence` with `operation=test`.

### 12. Example flows (concise)

#### 12.1 Fast path (structured worker)
1. Worker returns JSON `ArtifactBundle`.
2. GRISP computes `sha256` for each file and bundle, stores artifact.
3. Static validation passes.
4. Compile tool invoked → `ToolResult` recorded as `Evidence`.
5. Tests run → `Evidence`.
6. Final verification re-hashes bytes and re-runs compile/tests.
7. Commit transaction writes to `/final` and records `Decision`.

#### 12.2 Compatibility path (Markdown)
1. Worker returns Markdown with code fences.
2. GRISP parser extracts code blocks deterministically; if ambiguous → `PARSE_ERROR`.
3. If parsed, proceed as fast path.

#### 12.3 Failure path (malformed)
1. Worker returns UI tokens and malformed code (like your logs).
2. Parser returns `PARSE_ERROR`.
3. Orchestrator issues `REPAIR_REQUEST` to worker with original response and diagnostics.
4. If repair fails after configured retries, task moves to `REPORT` with `POLICY_REJECTED` or `PARSE_FAILED`.

### GARP 1.0 Protocol Specification

**Purpose**  
A stable, framed, event-driven transport between GRISP and a browser AI gateway. GARP provides request correlation, streaming events, cancellation, and session/tab identity.

#### Framing and Wire Format

**Frame layout**  
- **Transport:** TCP localhost, UTF-8 payloads.  
- **Frame header:** 4-byte unsigned big-endian payload length followed by JSON payload bytes. This simple framing prevents newline ambiguity and supports binary-safe payloads.

**Recommended extended frame header** (optional for future-proofing)
```
magic[4]         // ASCII 'GARP'
version[1]       // 1
flags[1]         // bitflags
header_length[2] // length of header metadata
payload_length[4]// length of JSON payload
message_type[2]  // numeric code
reserved[2]
request_id[16]   // UUID bytes
session_id[16]   // UUID bytes
payload[...]     // JSON UTF-8
```

**Minimum required framing**  
- 4-byte BE length + JSON payload. JSON must include `protocol`, `type`, `request_id`, and `session_id` fields.

#### Core message envelope (JSON)

All payloads must include these top-level fields:

```json
{
  "protocol": "GARP/1.0",
  "type": "string",
  "request_id": "uuid",
  "session_id": "uuid",
  "tab_id": "uuid",
  "message_id": "uuid",
  "sequence": 1,
  "payload": { }
}
```

**Field semantics**  
- **protocol**: must be `GARP/1.0`.  
- **type**: message type such as `hello`, `prompt`, `prompt_ack`, `generation_delta`, `generation_completed`, `generation_failed`, `cancel_ack`, `ping`, `pong`, `list_tabs`, `open_tab`, `close_tab`.  
- **request_id**: client-generated UUID for correlation.  
- **session_id**: gateway session identifier bound to provider and tab.  
- **tab_id**: stable GUID for the browser tab.  
- **message_id**: provider message identifier.  
- **sequence**: integer sequence number for streaming deltas.  
- **payload**: type-specific JSON object.

#### Core commands and events

**HELLO**  
- Client -> Gateway: negotiate features.  
- Gateway -> Client: `hello_ack` with `features` array.

**PROMPT**  
- Client -> Gateway: submit prompt. Gateway returns immediate `prompt_ack`. Provider generation streams as `generation_delta` events and ends with `generation_completed`.

**CANCEL_PROMPT**  
- Client -> Gateway: request cancellation. Gateway returns `cancel_ack` and attempts to cancel provider generation.

**LIST_TABS OPEN_TAB CLOSE_TAB SELECT_TAB**  
- Tab management commands using stable `tab_id` GUIDs.

**SUBSCRIBE_RESPONSE**  
- Client subscribes to asynchronous response events for a `request_id`.

#### Streaming event types

- `prompt_ack` — acknowledges prompt accepted.  
- `generation_delta` — partial text or structured chunk. Must include `sequence`.  
- `generation_progress` — optional progress metrics.  
- `generation_completed` — final content. Includes `finish_reason`.  
- `generation_failed` — includes `error` and `provider_state`.  
- `navigation` — tab navigation events.  
- `provider_error` — provider-level errors.  
- `session_changed` — session lifecycle events.

#### Provider compatibility and parsing

- Providers need not natively emit `ArtifactBundle`. The gateway must forward raw provider text as `generation_delta`/`generation_completed`.  
- GRISP must parse the provider text into `ArtifactBundle` at the boundary. If parsing fails, return `PARSE_ERROR` evidence and request a repair.  
- Structured output from provider is fast path. Markdown compatibility path is allowed. Ambiguous or malformed content must be rejected.

### B Delphi reference parser (compatibility + strict paths)

**Purpose**  
Deterministically parse provider responses (structured JSON envelope, fenced Markdown, or raw text) into a canonical `ArtifactBundle` or return a `PARSE_ERROR` result. The parser implements the fast path (structured JSON), the compatibility path (Markdown code fences with optional filename headers), and rejects ambiguous or malformed responses.

**Unit: `GrispArtifactParser.pas`**

```pascal
unit GrispArtifactParser;

interface

uses
  System.SysUtils, System.Classes, System.JSON, System.Hash;

type
  TParseResultStatus = (prsOk, prsParseError);

  TArtifactFile = record
    Filename: string;
    Language: string;
    Kind: string;
    Content: string; // UTF-8
    ContentEncoding: string; // 'utf-8' or 'base64'
    Sha256: string;
    SizeBytes: Integer;
  end;

  TArtifactBundle = record
    ArtifactId: string; // sha256 hex of canonical bundle bytes
    TaskId: string;
    ParentArtifactId: string;
    Revision: Integer;
    Files: TArray<TArtifactFile>;
    Provenance: TJSONObject;
    ArtifactKind: string;
    Language: string;
    Metadata: TJSONObject;
  end;

  TParseResult = record
    Status: TParseResultStatus;
    Bundle: TArtifactBundle;
    ErrorMessage: string;
  end;

function ParseProviderResponse(const RawResponse: string; const TaskId: string): TParseResult;

implementation

uses
  System.RegularExpressions, System.NetEncoding;

{ Helper: compute SHA256 hex of UTF8 bytes }
function SHA256Hex(const S: string): string;
var
  B: TBytes;
begin
  B := TEncoding.UTF8.GetBytes(S);
  Result := THashSHA2.GetHashString(B, SHA256);
  Result := LowerCase(Result);
end;

{ Helper: canonical serialization for bundle files (simple deterministic JSON ordering) }
function CanonicalBundleHash(const Files: TArray<TArtifactFile>): string;
var
  I: Integer;
  SB: TStringBuilder;
begin
  SB := TStringBuilder.Create;
  try
    for I := Low(Files) to High(Files) do
    begin
      SB.Append(Files[I].Filename);
      SB.Append('|');
      SB.Append(Files[I].Language);
      SB.Append('|');
      SB.Append(Files[I].Kind);
      SB.Append('|');
      SB.Append(Files[I].Sha256);
      SB.Append('|');
    end;
    Result := SHA256Hex(SB.ToString);
  finally
    SB.Free;
  end;
end;

{ Extract first fenced code block; returns header (if any) and code }
function ExtractFirstFencedBlock(const S: string; out Header, Code: string): Boolean;
var
  RE: TRegEx;
  M: TMatch;
begin
  Header := '';
  Code := '';
  RE := TRegEx.Create('```(?:\s*([^\r\n]+))?\r?\n([\s\S]*?)\r?\n```', [roIgnoreCase]);
  M := RE.Match(S);
  if M.Success then
  begin
    Header := Trim(M.Groups[1].Value);
    Code := M.Groups[2].Value;
    Exit(True);
  end;
  Result := False;
end;

{ Try parse structured JSON envelope (fast path) }
function TryParseStructured(const Raw: string; out Bundle: TArtifactBundle): Boolean;
var
  JsonVal, FilesArr, FileObj, ProvObj: TJSONValue;
  JsonObj: TJSONObject;
  I: Integer;
  AF: TArtifactFile;
  JA: TJSONArray;
begin
  Result := False;
  try
    JsonVal := TJSONObject.ParseJSONValue(Raw);
    if not (JsonVal is TJSONObject) then Exit;
    JsonObj := JsonVal as TJSONObject;
    if not JsonObj.TryGetValue('files', FilesArr) then Exit;
    JA := FilesArr as TJSONArray;
    SetLength(Bundle.Files, JA.Count);
    for I := 0 to JA.Count - 1 do
    begin
      FileObj := JA.Items[I];
      AF.Filename := (FileObj as TJSONObject).GetValue<string>('filename', '');
      AF.Language := (FileObj as TJSONObject).GetValue<string>('language', '');
      AF.Kind := (FileObj as TJSONObject).GetValue<string>('kind', 'source');
      AF.ContentEncoding := (FileObj as TJSONObject).GetValue<string>('content_encoding', 'utf-8');
      AF.Content := (FileObj as TJSONObject).GetValue<string>('content', '');
      AF.SizeBytes := Length(TEncoding.UTF8.GetBytes(AF.Content));
      if AF.ContentEncoding = 'base64' then
        AF.Sha256 := SHA256Hex(TNetEncoding.Base64.DecodeStringToBytes(AF.Content).ToString)
      else
        AF.Sha256 := SHA256Hex(AF.Content);
      Bundle.Files[I] := AF;
    end;
    Bundle.ArtifactId := CanonicalBundleHash(Bundle.Files);
    Bundle.TaskId := JsonObj.GetValue<string>('task_id', '');
    Bundle.ParentArtifactId := JsonObj.GetValue<string>('parent_artifact_id', '');
    Bundle.Revision := JsonObj.GetValue<Integer>('revision', 1);
    ProvObj := JsonObj.GetValue('provenance');
    if ProvObj <> nil then
      Bundle.Provenance := ProvObj.Clone as TJSONObject
    else
      Bundle.Provenance := TJSONObject.Create;
    Bundle.ArtifactKind := JsonObj.GetValue<string>('artifact_kind', 'EXECUTABLE');
    Bundle.Language := JsonObj.GetValue<string>('language', '');
    Bundle.Metadata := TJSONObject.Create;
    Result := True;
  except
    Result := False;
  end;
end;

{ Compatibility path: parse Markdown fenced block and optional header like "Pascal/Delphi:HelloWorld.dpr" }
function TryParseMarkdown(const Raw: string; const TaskId: string; out Bundle: TArtifactBundle): Boolean;
var
  Header, Code, Filename, Lang: string;
  AF: TArtifactFile;
begin
  Result := False;
  if not ExtractFirstFencedBlock(Raw, Header, Code) then Exit;
  // Clean common UI artifacts
  Code := TRegEx.Replace(Code, '^(delphiCopyDownload|Delphiprogram|Pascalprogram)\s*', '', [roIgnoreCase]);
  // Determine filename from header if present
  Filename := '';
  Lang := '';
  if Header <> '' then
  begin
    if Header.Contains(':') then
    begin
      Filename := Trim(Header.Substring(Header.IndexOf(':') + 1));
      Lang := Trim(Header.Substring(0, Header.IndexOf(':')));
    end
    else
      Filename := Trim(Header);
  end;
  if Filename = '' then
  begin
    // derive filename from language hint or default
    if Lang = '' then Lang := 'delphi';
    Filename := 'program.' + LowerCase(Lang);
    if SameText(Lang, 'delphi') or SameText(Lang, 'pascal') then
      Filename := 'HelloWorld.dpr';
  end;
  AF.Filename := Filename;
  AF.Language := IfThen(Lang = '', 'delphi', LowerCase(Lang));
  AF.Kind := 'source';
  AF.ContentEncoding := 'utf-8';
  AF.Content := Code;
  AF.SizeBytes := Length(TEncoding.UTF8.GetBytes(AF.Content));
  AF.Sha256 := SHA256Hex(AF.Content);
  SetLength(Bundle.Files, 1);
  Bundle.Files[0] := AF;
  Bundle.TaskId := TaskId;
  Bundle.ParentArtifactId := '';
  Bundle.Revision := 1;
  Bundle.Provenance := TJSONObject.Create;
  Bundle.ArtifactKind := 'EXECUTABLE';
  Bundle.Language := AF.Language;
  Bundle.Metadata := TJSONObject.Create;
  Bundle.ArtifactId := CanonicalBundleHash(Bundle.Files);
  Result := True;
end;

function ParseProviderResponse(const RawResponse: string; const TaskId: string): TParseResult;
var
  Bundle: TArtifactBundle;
begin
  Result.Status := prsParseError;
  Result.ErrorMessage := 'Unparsed';
  // Fast path: structured JSON envelope
  if TryParseStructured(RawResponse, Bundle) then
  begin
    Result.Status := prsOk;
    Result.Bundle := Bundle;
    Exit;
  end;
  // Compatibility path: Markdown fenced code block
  if TryParseMarkdown(RawResponse, TaskId, Bundle) then
  begin
    // Basic static validation: must start with 'program' or 'unit' for Delphi
    if (Pos(LowerCase('program'), LowerCase(Bundle.Files[0].Content)) = 1) or
       (Pos(LowerCase('unit'), LowerCase(Bundle.Files[0].Content)) = 1) then
    begin
      Result.Status := prsOk;
      Result.Bundle := Bundle;
      Exit;
    end
    else
    begin
      Result.Status := prsParseError;
      Result.ErrorMessage := 'Static validation failed: missing program/unit header';
      Exit;
    end;
  end;
  Result.Status := prsParseError;
  Result.ErrorMessage := 'No structured envelope or fenced code block found';
end;

end.
```

### E State-machine pseudocode (deterministic orchestrator)

**Purpose**  
Deterministic orchestrator with explicit transitions, evidence gating, and no implicit acceptance.

**Pseudocode (language-agnostic)**

```text
STATE = TASK_ACCEPTED

on EVENT TaskSubmitted(task):
  persist(task)
  transition(TASK_NORMALIZED)

STATE TASK_NORMALIZED:
  normalized = normalize(task)
  if normalized.invalid:
    emit Decision(REJECTED, reason="normalize_failed")
    transition(REPORT)
  else
    create work item
    transition(CANDIDATE_GENERATION)

STATE CANDIDATE_GENERATION:
  for worker in select_workers(task):
    request_id = send_prompt(worker, task.prompt)
    record pending_request(request_id, worker)
  wait for responses or timeout
  if no responses:
    transition(REPORT) // or retry policy
  else
    transition(ARTIFACT_PARSE)

STATE ARTIFACT_PARSE:
  for each response:
    parse_result = parse_response(response.raw, task.task_id)
    record Evidence(parse_op, parse_result)
    if parse_result.status == PARSE_ERROR:
      mark candidate rejected
    else
      store ArtifactBundle
  if no parsed candidates:
    transition(PARSE_FAILED)
  else
    transition(STATIC_VALIDATION)

STATE STATIC_VALIDATION:
  for each candidate:
    static_result = static_validate(candidate)
    record Evidence(static_validate, static_result)
    if static_result.status != ok:
      mark candidate rejected
  if no candidates remain:
    transition(STATIC_FAILED)
  else
    transition(COMPILE_PENDING)

STATE COMPILE_PENDING:
  for each candidate requiring compile:
    tool_result = compile(candidate)
    record Evidence(compile, tool_result)
    if tool_result.status != ok:
      mark candidate compile_failed
  if no compiled candidates:
    transition(COMPILE_FAILED)
  else
    transition(TEST_PENDING or ADVERSARIAL_REVIEW)

STATE TEST_PENDING:
  for each candidate with tests:
    for test in tests:
      tr = run_test(candidate, test)
      record Evidence(test, tr)
      if tr.status != ok:
        mark candidate test_failed
  if no candidates pass tests:
    transition(TEST_FAILED)
  else
    transition(ADVERSARIAL_REVIEW)

STATE ADVERSARIAL_REVIEW:
  optionally run adversarial LLMs or static analyzers
  record Evidence(adversarial, results)
  transition(CANDIDATE_RANKING)

STATE CANDIDATE_RANKING:
  eligible = filter(candidates, objective_gates_passed)
  if eligible.empty:
    transition(REPORT)
  else
    rank_by_quality(eligible) // subjective scores allowed only now
    winner = eligible.top
    transition(FINAL_VERIFICATION with winner)

STATE FINAL_VERIFICATION:
  rehash = hash(winner.bundle_bytes)
  if rehash != winner.artifact_id:
    record Evidence(hash_mismatch)
    transition(VERIFICATION_FAILED)
  recompile_result = compile_exact_bytes(winner)
  record Evidence(compile_final, recompile_result)
  rerun_tests = run_tests_exact_bytes(winner)
  record Evidence(test_final, rerun_tests)
  policy_result = policy_check(winner)
  record Evidence(policy_check, policy_result)
  if all final evidence ok:
    transition(COMMIT_PENDING)
  else
    transition(VERIFICATION_FAILED)

STATE COMMIT_PENDING:
  begin transaction
    write files to /workspace/final/<artifact_id> atomically
    write Decision(accepted)
  commit
  record Evidence(commit)
  transition(COMMITTED)

STATE REPORT:
  assemble report with all evidence
  notify user
  end

// Failure states: PARSE_FAILED, STATIC_FAILED, COMPILE_FAILED, TEST_FAILED, VERIFICATION_FAILED
// Each failure state records evidence and does not auto-accept.

```

**Key properties**
- Every transition that advances a candidate requires recorded `Evidence`.
- Subjective LLM scores are used only after objective gates pass.
- Retries are reason-specific and bounded by policy.
- Cancellation aborts pending tool runs and pending prompts and records `Evidence(status=timed_out)`.

### Canonical Bundle Canonicalization Algorithm (spec)

**Goal:** produce a deterministic byte sequence for an `ArtifactBundle` so that independent implementations compute the same SHA‑256 `artifact_id`.

**Principles**
- **Determinism:** canonical bytes must be identical across platforms for the same logical bundle.
- **Stability:** ordering and formatting rules are fixed and explicit.
- **Simplicity:** use UTF‑8 and JSON canonicalization rules that are easy to implement.
- **Losslessness:** all required fields are preserved; optional fields may be omitted if null.

**Canonicalization steps (ordered)**

1. **Normalize file contents**
   - Convert each file `content` to UTF‑8 bytes.
   - Normalize line endings to LF (`\n`).
   - Trim no content bytes; preserve exact content after normalization.
   - If `content_encoding` is `base64`, decode to bytes and then treat as binary content; for canonical JSON embed as base64 string (see step 4).

2. **Canonical file record**
   - For each file produce a JSON object with **exact** keys in this order:
     1. `filename` (string)
     2. `language` (string or `""`)
     3. `kind` (string)
     4. `content_encoding` (string: `"utf-8"` or `"base64"`)
     5. `content_sha256` (hex lowercase) — SHA‑256 of the normalized bytes of the file content
     6. `size_bytes` (integer)
   - **Do not** include the raw `content` in the canonical bundle bytes (to keep canonical bytes compact and avoid encoding differences). The content hash and size are sufficient to identify content deterministically.

3. **Sort files**
   - Sort the array of canonical file records by **filename** using Unicode codepoint order (binary comparison of UTF‑8 bytes). If filenames collide, secondary sort by `content_sha256`.

4. **Canonical bundle object**
   - Build a JSON object with **exact** keys in this order:
     1. `task_id` (string or `""`)
     2. `parent_artifact_id` (string or `""`)
     3. `revision` (integer)
     4. `artifact_kind` (string)
     5. `language` (string or `""`)
     6. `files` (array of canonical file records from step 2)
     7. `provenance` (object) — include only these keys in this order if present: `provider`, `worker_id`, `session_id`, `message_id`, `prompt_hash`, `response_hash`, `created_at`. Omit nulls.
     8. `metadata` (object) — canonicalize keys sorted by codepoint; values must be JSON primitives or nested objects canonicalized recursively with sorted keys.
   - **Do not** include `artifact_id` in the canonical bytes.

5. **JSON canonicalization rules**
   - Use UTF‑8 encoding.
   - No insignificant whitespace: **no** spaces or line breaks outside those required by JSON syntax.
   - Objects: keys appear in the exact order specified above; nested objects must follow the same rule (sorted keys for `metadata`).
   - Arrays: preserve order as produced by step 3.
   - Strings: use JSON string escaping per RFC 8259; use `\uXXXX` escapes for control characters; do not escape non‑ASCII characters (keep UTF‑8).
   - Numbers: use shortest decimal representation without leading zeros (e.g., `0`, `1`, `123.45`).
   - Booleans and null: `true`, `false`, `null`.

6. **Byte sequence**
   - Serialize the canonical JSON object using the canonicalization rules to a UTF‑8 byte sequence. This byte sequence is the canonical bundle bytes.

7. **artifact_id**
   - Compute `artifact_id = "sha256:" + hex_lowercase(SHA256(canonical_bytes))`.

8. **File content hashes**
   - For each file, compute `content_sha256 = hex_lowercase(SHA256(normalized_file_bytes))` and include it in the canonical file record.

**Rationale**
- Excluding raw content from the canonical bundle bytes keeps the canonicalization deterministic and compact while still uniquely identifying content via `content_sha256`.
- The ordered keys and sorted `files` array ensure identical serialization across implementations.

### Reference Implementation — Node.js (canonicalization + artifact_id)

**File:** `canonicalizeBundle.js`  
```javascript
// Node.js reference: canonicalizeBundle.js
// Usage: node canonicalizeBundle.js bundle.json
const fs = require('fs');
const crypto = require('crypto');

function sha256Hex(buf) {
  return crypto.createHash('sha256').update(buf).digest('hex');
}

function normalizeLineEndings(buf) {
  // Convert CRLF -> LF
  return Buffer.from(buf.toString('utf8').replace(/\r\n/g, '\n'), 'utf8');
}

function canonicalizeFileRecord(file) {
  // file: { filename, language, kind, content, content_encoding }
  let contentBytes;
  if ((file.content_encoding || 'utf-8') === 'base64') {
    contentBytes = Buffer.from(file.content, 'base64');
  } else {
    contentBytes = normalizeLineEndings(Buffer.from(file.content, 'utf8'));
  }
  const contentSha = sha256Hex(contentBytes);
  return {
    filename: file.filename,
    language: file.language || '',
    kind: file.kind || 'source',
    content_encoding: file.content_encoding || 'utf-8',
    content_sha256: contentSha,
    size_bytes: contentBytes.length
  };
}

function jsonStringifyCanonical(obj) {
  // Minimal canonical JSON serializer following the spec rules:
  // - No extra whitespace
  // - Keys in objects must be in the order provided by the object
  // For metadata objects we ensure keys are sorted.
  return JSON.stringify(obj);
}

function canonicalizeBundle(bundle) {
  // bundle: { task_id, parent_artifact_id, revision, artifact_kind, language, files[], provenance, metadata }
  const fileRecords = bundle.files.map(canonicalizeFileRecord);
  // sort by filename (UTF-8 codepoint order)
  fileRecords.sort((a, b) => {
    const A = Buffer.from(a.filename, 'utf8');
    const B = Buffer.from(b.filename, 'utf8');
    return A.compare(B);
  });

  // Build canonical object with exact key order
  const canonical = {
    task_id: bundle.task_id || '',
    parent_artifact_id: bundle.parent_artifact_id || '',
    revision: bundle.revision || 1,
    artifact_kind: bundle.artifact_kind || 'EXECUTABLE',
    language: bundle.language || '',
    files: fileRecords,
    provenance: {},
    metadata: bundle.metadata || {}
  };

  // Provenance: include keys in fixed order if present
  const prov = bundle.provenance || {};
  const provOrdered = {};
  ['provider','worker_id','session_id','message_id','prompt_hash','response_hash','created_at'].forEach(k => {
    if (prov[k] !== undefined && prov[k] !== null && prov[k] !== '') provOrdered[k] = prov[k];
  });
  canonical.provenance = provOrdered;

  // For metadata, ensure deterministic key order
  function sortObjectKeys(obj) {
    if (obj === null || typeof obj !== 'object' || Array.isArray(obj)) return obj;
    const keys = Object.keys(obj).sort();
    const out = {};
    for (const k of keys) out[k] = sortObjectKeys(obj[k]);
    return out;
  }
  canonical.metadata = sortObjectKeys(canonical.metadata);

  // Serialize canonical JSON (no extra whitespace)
  const canonicalBytes = Buffer.from(jsonStringifyCanonical(canonical), 'utf8');
  const artifactId = 'sha256:' + sha256Hex(canonicalBytes);
  return { canonicalBytes, artifactId, fileRecords };
}

// CLI
if (require.main === module) {
  const path = process.argv[2];
  if (!path) {
    console.error('Usage: node canonicalizeBundle.js bundle.json');
    process.exit(2);
  }
  const raw = fs.readFileSync(path, 'utf8');
  const bundle = JSON.parse(raw);
  const { artifactId, canonicalBytes, fileRecords } = canonicalizeBundle(bundle);
  console.log('artifact_id:', artifactId);
  console.log('canonical_bytes_length:', canonicalBytes.length);
  console.log('file_records:', JSON.stringify(fileRecords, null, 2));
}
```

**Notes**
- This reference uses `JSON.stringify` for compact JSON. For stricter canonicalization (e.g., deterministic escaping of control characters), replace `jsonStringifyCanonical` with a dedicated canonical JSON serializer (RFC 8785 or a custom implementation).
- The Node example computes `content_sha256` and `artifact_id` per the algorithm.

```pascal
unit GrispCanonical;

interface

uses
  System.SysUtils, System.Classes, System.JSON, System.Hash, System.Generics.Collections;

type
  TArtifactFile = record
    Filename: string;
    Language: string;
    Kind: string;
    Content: string; // UTF-8
    ContentEncoding: string; // 'utf-8' or 'base64'
    ContentSha256: string;
    SizeBytes: Integer;
  end;

  TArtifactBundle = record
    TaskId: string;
    ParentArtifactId: string;
    Revision: Integer;
    ArtifactKind: string;
    Language: string;
    Files: TArray<TArtifactFile>;
    Provenance: TJSONObject;
    Metadata: TJSONObject;
  end;

function SHA256HexOfBytes(const B: TBytes): string;
function NormalizeLineEndings(const S: string): string;
function ComputeFileRecord(const Filename, Language, Kind, Content, ContentEncoding: string): TArtifactFile;
function CanonicalizeBundle(const Bundle: TArtifactBundle; out CanonicalBytes: TBytes): string;

implementation

uses
  System.NetEncoding, System.Character;

function SHA256HexOfBytes(const B: TBytes): string;
begin
  Result := THashSHA2.GetHashString(B, SHA256);
  Result := LowerCase(Result);
end;

function NormalizeLineEndings(const S: string): string;
begin
  // Convert CRLF to LF
  Result := S.Replace(#13#10, #10);
end;

function ComputeFileRecord(const Filename, Language, Kind, Content, ContentEncoding: string): TArtifactFile;
var
  Bytes: TBytes;
  Decoded: TBytes;
begin
  if ContentEncoding.ToLower = 'base64' then
  begin
    Decoded := TNetEncoding.Base64.DecodeStringToBytes(Content);
    Bytes := Decoded;
  end
  else
  begin
    Bytes := TEncoding.UTF8.GetBytes(NormalizeLineEndings(Content));
  end;
  Result.Filename := Filename;
  Result.Language := Language;
  Result.Kind := Kind;
  Result.ContentEncoding := IfThen(ContentEncoding = '', 'utf-8', ContentEncoding);
  Result.SizeBytes := Length(Bytes);
  Result.ContentSha256 := SHA256HexOfBytes(Bytes);
end;

function JSONObjectToCanonicalString(Obj: TJSONObject): string;
var
  // For metadata we need sorted keys; this helper returns compact JSON with sorted keys
  Keys: TArray<string>;
  I: Integer;
  V: TJSONValue;
  SB: TStringBuilder;
begin
  SB := TStringBuilder.Create;
  try
    Keys := Obj.Keys.ToArray;
    TArray.Sort<string>(Keys);
    SB.Append('{');
    for I := 0 to Length(Keys)-1 do
    begin
      if I > 0 then SB.Append(',');
      SB.Append('"' + Keys[I] + '":');
      V := Obj.GetValue(Keys[I]);
      SB.Append(V.ToJSON);
    end;
    SB.Append('}');
    Result := SB.ToString;
  finally
    SB.Free;
  end;
end;

function CanonicalizeBundle(const Bundle: TArtifactBundle; out CanonicalBytes: TBytes): string;
var
  FileRecs: TList<TArtifactFile>;
  I: Integer;
  CanonicalObj: TJSONObject;
  FilesArr: TJSONArray;
  FileObj: TJSONObject;
  ProvObj: TJSONObject;
  MetaStr: string;
  CanonicalStr: string;
begin
  FileRecs := TList<TArtifactFile>.Create;
  try
    for I := Low(Bundle.Files) to High(Bundle.Files) do
      FileRecs.Add(Bundle.Files[I]);
    // sort by filename (UTF-8 codepoint)
    FileRecs.Sort(TComparer<TArtifactFile>.Construct(
      function(const L, R: TArtifactFile): Integer
      var
        LB, RB: TBytes;
      begin
        LB := TEncoding.UTF8.GetBytes(L.Filename);
        RB := TEncoding.UTF8.GetBytes(R.Filename);
        Result := CompareMem(LB, RB, Min(Length(LB), Length(RB))) and (Length(LB) - Length(RB));
        // fallback to string compare if needed
        if Result = 0 then
          Result := CompareText(L.Filename, R.Filename);
      end));

    // Build canonical JSON object with exact key order
    CanonicalObj := TJSONObject.Create;
    try
      CanonicalObj.AddPair('task_id', TJSONString.Create(Bundle.TaskId));
      CanonicalObj.AddPair('parent_artifact_id', TJSONString.Create(Bundle.ParentArtifactId));
      CanonicalObj.AddPair('revision', TJSONNumber.Create(Bundle.Revision));
      CanonicalObj.AddPair('artifact_kind', TJSONString.Create(Bundle.ArtifactKind));
      CanonicalObj.AddPair('language', TJSONString.Create(Bundle.Language));
      FilesArr := TJSONArray.Create;
      for I := 0 to FileRecs.Count - 1 do
      begin
        FileObj := TJSONObject.Create;
        FileObj.AddPair('filename', TJSONString.Create(FileRecs[I].Filename));
        FileObj.AddPair('language', TJSONString.Create(FileRecs[I].Language));
        FileObj.AddPair('kind', TJSONString.Create(FileRecs[I].Kind));
        FileObj.AddPair('content_encoding', TJSONString.Create(FileRecs[I].ContentEncoding));
        FileObj.AddPair('content_sha256', TJSONString.Create(FileRecs[I].ContentSha256));
        FileObj.AddPair('size_bytes', TJSONNumber.Create(FileRecs[I].SizeBytes));
        FilesArr.Add(FileObj);
      end;
      CanonicalObj.AddPair('files', FilesArr);

      // Provenance: include keys in fixed order if present
      ProvObj := TJSONObject.Create;
      if Assigned(Bundle.Provenance) then
      begin
        if Bundle.Provenance.GetValue('provider') <> nil then
          ProvObj.AddPair('provider', TJSONString.Create(Bundle.Provenance.GetValue('provider').Value));
        if Bundle.Provenance.GetValue('worker_id') <> nil then
          ProvObj.AddPair('worker_id', TJSONString.Create(Bundle.Provenance.GetValue('worker_id').Value));
        if Bundle.Provenance.GetValue('session_id') <> nil then
          ProvObj.AddPair('session_id', TJSONString.Create(Bundle.Provenance.GetValue('session_id').Value));
        if Bundle.Provenance.GetValue('message_id') <> nil then
          ProvObj.AddPair('message_id', TJSONString.Create(Bundle.Provenance.GetValue('message_id').Value));
        if Bundle.Provenance.GetValue('prompt_hash') <> nil then
          ProvObj.AddPair('prompt_hash', TJSONString.Create(Bundle.Provenance.GetValue('prompt_hash').Value));
        if Bundle.Provenance.GetValue('response_hash') <> nil then
          ProvObj.AddPair('response_hash', TJSONString.Create(Bundle.Provenance.GetValue('response_hash').Value));
        if Bundle.Provenance.GetValue('created_at') <> nil then
          ProvObj.AddPair('created_at', TJSONString.Create(Bundle.Provenance.GetValue('created_at').Value));
      end;
      CanonicalObj.AddPair('provenance', ProvObj);

      // Metadata: sort keys
      if Assigned(Bundle.Metadata) then
      begin
        MetaStr := JSONObjectToCanonicalString(Bundle.Metadata);
        CanonicalObj.AddPair('metadata', TJSONObject.ParseJSONValue(MetaStr) as TJSONObject);
      end
      else
        CanonicalObj.AddPair('metadata', TJSONObject.Create);

      // Serialize compact JSON (no extra whitespace)
      CanonicalStr := CanonicalObj.ToJSON; // Delphi's ToJSON is compact
      CanonicalBytes := TEncoding.UTF8.GetBytes(CanonicalStr);
      Result := 'sha256:' + SHA256HexOfBytes(CanonicalBytes);
    finally
      CanonicalObj.Free;
    end;
  finally
    FileRecs.Free;
  end;
end;

end.
```
