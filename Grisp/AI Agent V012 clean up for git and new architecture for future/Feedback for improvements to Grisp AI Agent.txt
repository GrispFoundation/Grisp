#### 3) JSON escaping & BOM handling
**Problems:**
- `EscapeJSON` does not escape control characters (e.g., `#10`, `#13`, `#9`) as `\n`, `\r`, `\t` and does not encode other non‑printable characters as `\uXXXX`.  
- `ReadAllInput` inspects string bytes for UTF‑8 BOM which is unreliable in modern Delphi where `string` is UTF‑16; using `TFile.ReadAllText` with `TEncoding` is safer.

**Fix (recommended):**

Replace `EscapeJSON` with a robust implementation:

```pascal
function EscapeJSON(const S: string): string;
var
  i: Integer;
  ch: Char;
  code: Word;
begin
  Result := '';
  for i := 1 to Length(S) do
  begin
    ch := S[i];
    case ch of
      '"' : Result := Result + '\"';
      '\' : Result := Result + '\\';
      #8  : Result := Result + '\b';
      #9  : Result := Result + '\t';
      #10 : Result := Result + '\n';
      #12 : Result := Result + '\f';
      #13 : Result := Result + '\r';
    else
      code := Ord(ch);
      if code < 32 then
        Result := Result + Format('\u%.4x', [code])
      else
        Result := Result + ch;
    end;
  end;
end;
```

Replace `ReadAllInput` file reading with `TFile.ReadAllText` and explicit `TEncoding` detection:

```pascal
uses
  System.IOUtils, System.SysUtils;

function ReadAllInput: string;
begin
  if ParamCount >= 1 then
  begin
    if not FileExists(ParamStr(1)) then
      raise Exception.CreateFmt('input file not found: %s', [ParamStr(1)]);
    Result := TFile.ReadAllText(ParamStr(1), TEncoding.UTF8);
  end
  else
    Result := TFile.ReadAllText('CON'); // or read from stdin via TStreamReader with TEncoding
  // Trim leading whitespace
  while (Length(Result) > 0) and (Result[1] <= ' ') do Delete(Result, 1, 1);
end;
```

(If you must support arbitrary encodings, use `TFile.ReadAllBytes` and detect BOM bytes explicitly, then decode.)

#### 4) Lexer token position accuracy
**Problem:** `ReadIdentOrKeyword`, `ReadNumber`, `ReadString` set `Result.Line`/`Result.Col` after consuming characters, so `Col` points after token end. This makes error messages show the wrong column.  
**Fix:** Capture `startLine := FLine; startCol := FCol;` before consuming, and set `Result.Line := startLine; Result.Col := startCol;`.

---

#### 5) Comment scanning robustness
**Problem:** `SkipWhitespaceAndComments` uses `FPos <= Length(FText)-1` and `FText[FPos+1]` checks; while correct in many cases, it’s clearer and safer to use `Peek` and `NextChar` and check for `#0`.  
**Fix:** Simplify block comment handling by checking `Peek` and `PeekNext` helper that returns `#0` when out of range.
