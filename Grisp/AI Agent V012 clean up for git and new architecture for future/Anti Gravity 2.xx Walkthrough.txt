2. GRISP VFS & Capability Security Hardening
GrispVfs.pas
:
ResolveSafe Security Enforcement:
Strictly rejects : (Windows drive letters, protocol schemes).
Strictly rejects .. (directory traversal escapes).
Enforces canonical normalization via NormalizePath.
Enforces boundary containment by strictly checking that physical path starts with FSandboxPhysicalRoot + PathDelim.
Extension-to-MIME Mapping: Added comprehensive mappings for .c, .pas, .py, .json, .txt, .bin, .exe.
Disk Backing Error Handling: Added proper return value checks and exception safety across WriteFile and DeleteFile.
GrispCapabilities.pas
:
Added TGrispCapability.DeduceMimeFromExtension.
Hardened TGrispCapability.ValidateWrite to validate both caller-provided MIME and extension-deduced MIME, preventing MIME spoofing (e.g. submitting an .exe file with a text/plain header).
GrispCore.pas
:
Implemented TGrispValidationResult.MakeAccepted and MakeRejected.
Implemented TGrispEngine.ValidatePlan(const Rules: TArray<TGrispRule>; const CapName: string): TGrispValidationResult with detailed failure tracking across all rules and actions.
MLCRD_Adapters.pas
:
Updated TGrispHarnessAdapterImpl.ValidatePlan to delegate to FEngine.ValidatePlan and return structured TGrispValidationResult.
