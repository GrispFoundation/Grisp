Maak eerst een nieuw GUI ontwerp laat alle onzin zoals cpu/gpu workspace usage en allerlei andere modern poespas achterwege, concentreer je op de kern activiteiten:

1. Chat window.
2. Eventueel een optionele think window die collapseable is waarin de gebruiker kan zie hoe de AI denkt.
3. Chat bar.
4. Session window/history, waarin de gebruiker de geschiedenis kan zien van chat sessies, onderwerp + dag + tijdstip.
5. Eventuele side panels aan rechter kant om plannen/work items te presenteren of in chat gui zelf, dat is nog beter, dus geen side panels als het kan.
6. Inderdaad een windows explorer, eventueel netjes weggewerkt linker kant, eventueel collapse oproepbaar voor als project moet worden uitgebreid, maar als eenmaal ingestelt kan dan eventueel weg, zelfde moet kunnen voor de session history om de rest te maximaliseren en daarop te kunnen focussen. Permissies moeten er ook in zitten, minstens read, write, execute, laten we daar eens mee beginnen.
