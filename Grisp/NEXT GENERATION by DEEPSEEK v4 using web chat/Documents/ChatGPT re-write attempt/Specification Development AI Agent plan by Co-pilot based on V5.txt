# ⭐ Step 2 — Firefox automation becomes the “peer”  
Your Firefox automation AI (Playwright, Selenium, AutoHotkey, or your own tool) acts as a **GSDA peer**.

It must:

- have a PeerID  
- have a SharedSecret  
- generate HMAC tokens  
- send JSON payloads to GSDA31  

Example:

```
PeerID = "peer:firefox"
SharedSecret = "mysecret"
Fingerprint = "local|adapter:firefox|endpoint:browser"
RoundID = "run:1234:round:0"
Token = HMAC(PeerID|Fingerprint|RoundID)
```

Then Firefox sends:

```
{
  "schema": "gsp/3.1",
  "content": "Extracted text from webpage",
  "content_id": "content:abc123"
}
```

GSDA31 authenticates and ingests it.
