What changed in V0.06

Planner returns a graph (PlannedGoal and PlannedTask) instead of an opaque plan blob.

Plan graph is separate from execution graph; instantiation helpers convert Planned* nodes into live Goal/Task.

Phase + status model retained (two fields), enabling a clear separation between planning and execution but introducing potential state-combination complexity.

Validation rules operate on the plan graph, but instantiation uses helper calls (procedural step).
